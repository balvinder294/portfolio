# Balvinder Singh — Portfolio

This repository contains the source code for my personal portfolio site.

The goal of this site is not to showcase every project or line of code, but to communicate **how I think about building and maintaining real-world software systems**.

The portfolio is intentionally simple, focused on clarity, readability, and long-term maintainability.

---

## About Me

I’m a senior full-stack engineer based in India, focused on **modernizing and stabilizing production systems**.

Most of my work involves:
- Improving performance and reliability in live systems
- Incrementally modernizing legacy applications
- Reducing operational risk during upgrades and migrations
- Helping teams regain confidence in growing codebases

I’ve worked primarily with **JavaScript, React, Node.js, Java**, and related backend technologies, often in environments where changes must be careful, predictable, and production-safe.

In addition to application development, I’ve also worked with CI/CD, deployments, and infrastructure, and I actively operate and maintain blockchain and Web3 infrastructure (validators, witness nodes, and supporting services).

---

## Why This Portfolio Exists

This portfolio is designed as a **signal**, not a résumé.

You won’t find:
- Skill percentages
- Detailed timelines
- Public client code
- NDA-protected projects

Instead, the site focuses on:
- Clear language
- Realistic project descriptions
- Production-oriented thinking
- Calm, senior-level positioning

If you’re evaluating this portfolio, the best indicator of fit is whether the **way problems are described** aligns with how you think about software.

---

## Tech Stack

The site is intentionally lightweight and boring by design.

- **Framework:** Next.js
- **UI:** Chakra UI / CSS
- **Language:** TypeScript
- **Deployment:** Vercel

No CMS, no heavy animation libraries, and no unnecessary complexity.

---

## Project Content

Project descriptions on the site are **high-level and NDA-safe**.

They are meant to:
- Provide context
- Explain constraints
- Highlight outcomes and decisions

They are not full case studies or code walkthroughs.
